# Expense Tracker & Analytics System

## Objective
Track income and expenses with SQLite CRUD operations, authentication, analytics, reports and charts.

## Install
```bash
pip install -r requirements.txt
```

## Run
```bash
python main.py
```

## Features
- User registration/login
- Password hashing with SHA-256
- Income and expense management
- SQLite CRUD
- Monthly analytics
- Matplotlib chart
- CSV report export
